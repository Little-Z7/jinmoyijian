# 官方页面工作流参考

此文件记录发布时曾观察到的界面，用于定位而非作为长期不变的站点规范。运行时必须先完成 [environment-check.md](environment-check.md) 中的能力检查，再重新读取官方页面；不要硬编码 DOM 顺序、坐标或 `lid` 参数。

## 入口与目标

- 征求意见入口：`http://www.npc.gov.cn/flcaw/`
- 用 URL 解析器验证主机名，只允许 `hostname === "npc.gov.cn"` 或 `hostname.endsWith(".npc.gov.cn")`；`notnpc.gov.cn` 一类相似域名不允许。
- 目标完整标题：`道路交通安全法（修订草案）征求意见`
- 只在目标仍位于“正在征求意见”区域且当前日期处于页面公布期限内时继续。

## 已观察到的信息录入页

选择目标草案后，网站会打开信息录入页，而不一定显示传统账号登录框。历史页面曾显示以下字段：

- 省份
- 姓名
- 职业
- 电子邮件
- 联系电话
- “进入”和“重新填写”操作

哪些字段必填、字段校验和按钮名称都必须以实时页面为准。整个个人信息页由用户完整接管，包括填写字段和点击会发送数据的“进入”“下一步”等控件；助手不得读取、回显、截图或记录这些字段。用户离开含敏感字段的页面并明确告知完成后，助手才能继续核对非敏感页面状态。

发布时，入口和信息录入页曾显示为明文 HTTP，HTTPS 探测未能建立连接。此状态可能变化，运行时必须重新检查。若仍不是有效 HTTPS，助手只能只读导航并在聊天中离线展示正文，不得在网页字段中输入内容，也不得点击发送个人信息或最终意见的按钮；警告风险并让用户本人决定和操作，不得绕过任何浏览器安全提示。

## 已观察到的意见页

历史页面证据显示：

- 左侧为草案条款目录，可按条款提出意见；
- 中间有意见文本框，截图提示“字数限制1000字”；
- 页面包含验证码输入、验证码图片、“清空”和“提交”；
- 附件预览区可能显示“无法加载插件”，这不等同于意见表单不可用。

这些均是历史界面证据。运行时应优先使用可访问名称、标签、占位符和可见文字定位，不能使用截图坐标。

## 模式映射

### 合并提交

仅在页面允许总体意见且用户明确选择时使用。不选择单一条款，把 [opinion-draft.md](opinion-draft.md) 中四条原文按原顺序、段间一个空行合并。填入前后都要按实时限制校验，不得依赖历史的 1000 字提示。

### 逐条款提交

使用以下目标条款映射，但必须与实时目录核对：

| 建议 | 目标条款 |
| --- | --- |
| 建议一 | 第四十八条 |
| 建议二 | 第八十二条 |
| 建议三 | 第十九条 |
| 建议四 | 第七十一条 |

每一条必须串行处理，并分别完成验证码、完整预览、最终确认和最多一次提交。不能把四条写成自动循环。

## 定位与核验原则

- 按完整草案标题和条款可见文本定位，避免模糊匹配同名草案。
- 页面打开新标签时，先确认新标签 URL 和标题，再继续。
- 条款不在当前视口时通过语义定位或滚动查找，不使用固定坐标。
- 读取文本框实时 `maxlength`、计数提示或校验反馈；三者冲突时停止。
- 只有明确成功提示或回执可证明成功。状态不明时零次自动重试。
